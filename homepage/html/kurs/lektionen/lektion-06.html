Die Schleifenvariable als Zahl verwenden, die sich bei jeder Runde verändert.

Für Lehrkräfte: Die aktuelle Schleifenvariable in jeder Runde laut mitsprechen: 8, 7, 6, … Dadurch wird die Verbindung zwischen Schleife und Gebäude sichtbar.

So sieht der Blockly-Bauplan aus

function pyramide
for i from 8 to 1 by -1
box Sandstone W i H 1 D i
up 1
end for
end function
preview function pyramide

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Starte mit `i = 8`.
  2. Lass `i` bis 1 herunterzählen.
  3. Verwende `i` für Breite und Tiefe.
  4. Bewege die Drohne nach jeder Ebene um 1 nach oben.

Was Blockly daraus als JavaScript macht

function pyramide() {
  for (var i = 8; i >= 1; i--) {
    drone.box("SANDSTONE",i,1,i);
    drone.up(1);
  }
};
pyramide();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Baue eine Treppe oder einen Turm, dessen Etagen bei jeder Wiederholung größer oder kleiner werden.

Typische Stolperstellen
  • Bei einer schrumpfenden Schleife muss die Schrittweite negativ sein.
  • Die Variable muss an den Zahleneingang eines Blocks angeschlossen werden können.

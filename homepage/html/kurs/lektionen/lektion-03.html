Für Lehrkräfte: Hier kann man erstmals ausdrücklich den Begriff **Parameter** einführen: Ein Befehl bleibt gleich, seine Eingaben verändern das Ergebnis.

So sieht der Blockly-Bauplan aus

function haus
box Dirt 7 1 7
up 1
box0 Cobblestone W 7 H 4 D 7
up 4
box Quartz 7 1 7
end function
preview function haus

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Baue einen Boden.
  2. Bewege die Drohne um 1 nach oben.
  3. Verwende `box0` für hohle Wände.
  4. Bewege die Drohne um die Wandhöhe nach oben.
  5. Baue ein flaches Dach.

Was Blockly daraus als JavaScript macht

function haus() {
  drone.box("DIRT",7,1,7);
  drone.up(1);
  drone.box0("COBBLESTONE",7,4,7);
  drone.up(4);
  drone.box("QUARTZ_BLOCK",7,1,7);
};
haus();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Erzeuge drei Hausvarianten: klein, breit und hoch. Verändere jeweils nur die Zahlen und Materialien.

Typische Stolperstellen
  • Nach dem Boden muss die Drohne nach oben, sonst beginnen Wände im Boden.
  • Vor dem Dach muss sie genau um die Wandhöhe nach oben bewegt werden.

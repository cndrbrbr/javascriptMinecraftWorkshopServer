Für Lehrkräfte: Jetzt lohnt sich ein kurzer Blick auf das erzeugte JavaScript: Blockly-Blöcke sind keine Magie, sondern schreiben strukturierten Code.

So sieht der Blockly-Bauplan aus

function haus
box0 Cobblestone W 7 H 4 D 7
up 4
box Quartz 7 1 7
down 4
end function
function strasse
repeat 8 times
call haus ()
right 10
end repeat
end function
preview function strasse

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Baue und teste erst `haus` allein.
  2. Füge die Hauptfunktion `strasse` hinzu.
  3. Rufe `haus` in einer `repeat`-Schleife auf.
  4. Verschiebe die Drohne nach jedem Haus.

Was Blockly daraus als JavaScript macht

function haus() {
  drone.box0("COBBLESTONE",7,4,7);
  drone.up(4);
  drone.box("QUARTZ_BLOCK",7,1,7);
  drone.down(4);
}
function strasse() {
  for (var n=0;n<8;n++) {
    haus();
    drone.right(10);
  }
}
strasse();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Baue zwei parallele Häuserreihen. Verwende eine zweite Funktion oder eine zweite Schleife.

Typische Stolperstellen
  • Die Hausfunktion sollte die Drohne wieder auf Bodenhöhe bringen.
  • Der Abstand muss groß genug sein, damit Häuser nicht überlappen.

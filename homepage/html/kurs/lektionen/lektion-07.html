Für Lehrkräfte: Funktion als selbst erfundenen neuen Baubefehl erklären. Das ist eine starke Brücke zum späteren textuellen Programmieren.

So sieht der Blockly-Bauplan aus

function saeule
box Quartz 1 6 1
end function
function halle
call saeule ()
fwd 4
call saeule ()
fwd 4
call saeule ()
end function
preview function halle

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Definiere zuerst `saeule`.
  2. Definiere danach `halle`.
  3. Rufe `saeule()` in der Halle mehrfach auf.
  4. Setze nur `halle` als Preview-Funktion.

Was Blockly daraus als JavaScript macht

function saeule() {
  drone.box("QUARTZ_BLOCK",1,6,1);
};
function halle() {
  saeule();
  drone.fwd(4);
  saeule();
  drone.fwd(4);
  saeule();
};
halle();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Kombiniere Funktionsaufruf und `repeat`, sodass eine Halle mit 10 Säulen entsteht.

Typische Stolperstellen
  • Jede Funktion braucht einen eindeutigen Namen.
  • Als Preview-Funktion die Hauptfunktion auswählen, nicht den kleinen Baustein.

Mit Schleifen in die Höhe

JavaScript
Schleifen + Variablen
Minecraft-Projekt
Hochhaus
Lernziel
Variablen und Schleifen werden kombiniert, um parametrische Gebäude zu erzeugen.

Ein Hochhaus besteht aus vielen ähnlichen Stockwerken – ideal für eine Schleife.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

var stockwerke = 12;

for (var i = 0; i < stockwerke; i++) {
    drone.box0("GLASS", 9, 3, 9);
    drone.up(3);
}

Schritt für Schritt

1. Höhe steuern

Ändere nur die Variable `stockwerke`.

2. Stockwerkshöhe

Speichere auch die Höhe eines Stockwerks in einer Variablen.

3. Dach

Baue nach der Schleife ein Dach.

Challenge:

Baue ein Hochhaus mit 15 Stockwerken und einem Dach aus QUARTZ_BLOCK. Jedes Stockwerk soll 3 Blöcke hoch sein.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

var stockwerke = 15;
var stockwerkHoehe = 3;
var breite = 9;

for (var i = 0; i < stockwerke; i++) {
    drone.box0("GLASS", breite, stockwerkHoehe, breite);
    drone.up(stockwerkHoehe);
}

drone.box("QUARTZ_BLOCK", breite, 1, breite);
Typische Fehler
  • Wenn `drone.up(...)` fehlt, landen alle Stockwerke übereinander.
  • Achte darauf, dass Dachbreite und Gebäudebreite zusammenpassen.
  • Große Werte können sehr große Bauwerke erzeugen – langsam steigern.

Für Lehrkräfte: Die IDE hat keinen Checkpoint-Block wie das neuere JSMN-API; deshalb ist das bewusste Zurückbewegen hier didaktisch wertvoll.

So sieht der Blockly-Bauplan aus

function feld
for zeile from 0 to 7
for spalte from 0 to 7
if (zeile + spalte) mod 2 = 0
box White Wool 1 1 1
else → box Black/Obsidian
right 1
nach Reihe: zurück + fwd 1
end function
preview function feld

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Baue zunächst nur eine Reihe mit 8 Feldern.
  2. Setze darum eine zweite Schleife für 8 Reihen.
  3. Nach jeder Reihe muss die Drohne horizontal zurück und eine Reihe vor.
  4. Füge erst danach das Farbmuster hinzu.

Was Blockly daraus als JavaScript macht

function feld() {
  for (var zeile=0; zeile<8; zeile++) {
    for (var spalte=0; spalte<8; spalte++) {
      if ((zeile + spalte) % 2 === 0) {
        drone.box("WHITE_WOOL",1,1,1);
      } else {
        drone.box("OBSIDIAN",1,1,1);
      }
      drone.right(1);
    }
    drone.left(8);
    drone.fwd(1);
  }
}
feld();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Erzeuge ein eigenes 8×8- oder 16×16-Pixelmuster.

Typische Stolperstellen
  • Nach jeder Zeile muss die Drohne um die gesamte Zeilenbreite zurück.
  • Zum Debuggen zuerst 3×3 statt 16×16 testen.

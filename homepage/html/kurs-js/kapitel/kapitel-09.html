Verschachtelte Schleifen

JavaScript
Zeilen und Spalten, verschachtelte Schleifen, 2D-Muster
Minecraft-Projekt
Schachbrett und Pixel-Art
Lernziel
Die Kinder erzeugen zweidimensionale Muster mit einer Schleife innerhalb einer anderen.

Eine Schleife baut eine Reihe. Eine zweite Schleife kann daraus viele Reihen machen.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

var groesse = 10;

for (var zeile = 0; zeile < groesse; zeile++) {
    drone.chkpt("zeile");

    for (var spalte = 0; spalte < groesse; spalte++) {
        if ((zeile + spalte) % 2 == 0) {
            drone.box("WHITE_CONCRETE");
        } else {
            drone.box("BLACK_CONCRETE");
        }
        drone.right();
    }

    drone.move("zeile");
    drone.fwd();
}

Schritt für Schritt

1. Größe verändern

Teste 6×6, 10×10 und 16×16.

2. Farben verändern

Baue ein rot-blaues Spielfeld.

3. Muster entwickeln

Ändere die Bedingung, sodass Streifen statt eines Schachbretts entstehen.

Challenge:

Baue ein 16×16 großes Pixel-Feld und erfinde mit Bedingungen ein eigenes geometrisches Muster.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

var groesse = 16;

for (var z = 0; z < groesse; z++) {
    drone.chkpt("reihe");

    for (var s = 0; s < groesse; s++) {
        if (z == s || z + s == groesse - 1) {
            drone.box("RED_CONCRETE");
        } else {
            drone.box("WHITE_CONCRETE");
        }
        drone.right();
    }

    drone.move("reihe").fwd();
}
Typische Fehler
  • Die innere Schleife läuft für jede Runde der äußeren Schleife vollständig durch.
  • Ein Checkpoint am Reihenanfang verhindert, dass der Drone schräg davonläuft.
  • Beim Debuggen zuerst kleine Größen wie 4×4 verwenden.

Für Lehrkräfte: Falls die Standard-Blockly-Logik ungewohnt ist, zuerst nur `if/else` mit einer einfachen Zahl demonstrieren und erst danach `%` verwenden.

So sieht der Blockly-Bauplan aus

function musterturm
for i from 1 to 12 by 1
if i mod 2 = 0
box White Wool 5 1 5
else
box Blue Wool 5 1 5
up 1
end if / for
end function
preview function musterturm

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Erzeuge eine `for`-Schleife mit 12 Ebenen.
  2. Prüfe, ob `i` gerade ist.
  3. Baue bei geraden Ebenen weiß, sonst blau.
  4. Bewege die Drohne in jeder Runde nach oben.

Was Blockly daraus als JavaScript macht

function musterturm() {
  for (var i=1;i<=12;i++) {
    if (i % 2 === 0) {
      drone.box("WHITE_WOOL",5,1,5);
    } else {
      drone.box("BLUE_WOOL",5,1,5);
    }
    drone.up(1);
  }
}
musterturm();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Erfinde ein Muster mit drei Farben, z. B. jedes dritte Stockwerk Gold.

Typische Stolperstellen
  • Die `up`-Bewegung gehört nach die Entscheidung, aber noch in die Schleife.
  • Bei Bedingungen darauf achten, ob die IDE einen Zahlen- oder Wahrheitswert erwartet.

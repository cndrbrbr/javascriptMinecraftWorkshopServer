Für Lehrkräfte: Das Problem vor dem Fachbegriff stellen: „Müssen wir dieselben fünf Blöcke wirklich zwanzigmal zusammenklicken?“

So sieht der Blockly-Bauplan aus

function laternen
repeat 10 times
box Iron 1 4 1
up 4
box Glowstone 1 1 1
down 4
fwd 5
end repeat
end function
preview function laternen

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Baue zunächst zwei Laternen ohne Schleife.
  2. Markiere die Befehle, die sich wiederholen.
  3. Ersetze sie durch `repeat 10 times`.
  4. Ändere nur die Wiederholungszahl und beobachte die Wirkung.

Was Blockly daraus als JavaScript macht

function laternen() {
  for (var count = 0; count < 10; count++) {
    drone.box("IRON_BLOCK",1,4,1);
    drone.up(4);
    drone.box("GLOWSTONE",1,1,1);
    drone.down(4);
    drone.fwd(5);
  }
};
laternen();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Baue 20 Laternen mit 6 Blöcken Abstand.

Typische Stolperstellen
  • Die Bewegung zur nächsten Laterne muss innerhalb der Schleife liegen.
  • Nach der Lampe muss die Drohne wieder auf Ausgangshöhe zurück.

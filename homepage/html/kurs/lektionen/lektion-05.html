Für Lehrkräfte: Variablen als beschriftete Schachteln erklären: In `hoehe` liegt gerade die Zahl 5.

So sieht der Blockly-Bauplan aus

set hoehe to 5
function turm
box0 Stone W 7 H hoehe D 7
move up by hoehe
box Quartz 7 1 7
end function
preview function turm

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Erstelle die Variable `hoehe`.
  2. Setze sie auf 5.
  3. Verwende sie als Höhe des Gebäudes.
  4. Benutze `move by var`, damit die Drohne genau um dieselbe Höhe nach oben fährt.

Was Blockly daraus als JavaScript macht

var hoehe = 5;
function turm() {
  drone.box0("STONE",7,hoehe,7);
  drone.up(hoehe);
  drone.box("QUARTZ_BLOCK",7,1,7);
};
turm();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Lege zusätzlich `breite` an und steuere damit Wand- und Dachbreite.

Typische Stolperstellen
  • Für variable Bewegungsweiten braucht man den Block `move by var`.
  • Wenn Dach und Wände dieselbe Größe haben sollen, überall dieselbe Variable verwenden.

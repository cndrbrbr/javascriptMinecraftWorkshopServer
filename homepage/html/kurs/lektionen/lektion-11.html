Für Lehrkräfte: Das ist eine gute Teamarbeits-Einheit: Kinder können Module getrennt entwickeln und später zusammenfügen.

So sieht der Blockly-Bauplan aus

haus.json
+ baum.json
+ laterne.json
→ 3D Vorschau

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Speichere ein Haus als Blockly-Datei.
  2. Erstelle und speichere getrennt einen Baum.
  3. Erstelle und speichere eine Laterne.
  4. Lade ein Modell normal und die anderen mit **XML hinzuladen**.
  5. Teste alle Modelle gemeinsam in der 3D-Vorschau.

Was Blockly daraus als JavaScript macht

// Die IDE kann mehrere gespeicherte Blockly-Modelle hinzuladen.
// Wichtig: eindeutige Funktionsnamen verwenden.
function haus(){ /* ... */ }
function baum(){ /* ... */ }
function laterne(){ /* ... */ }
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Erstelle mit einem Partner drei unabhängige Bauobjekte und kombiniert sie anschließend.

Typische Stolperstellen
  • Funktionen dürfen beim Zusammenführen nicht gleich heißen.
  • `XML laden` ersetzt den Workspace; `XML hinzuladen` ergänzt ihn.

Checkpoints für komplexe Bauwerke

JavaScript
Zustand speichern, Position wiederherstellen
Minecraft-Projekt
Villa mit mehreren Teilen
Lernziel
Die Kinder lernen, bei komplexen Bauwerken von einem bekannten Ausgangspunkt weiterzubauen.

`chkpt()` ist ein Lesezeichen für den Drone. `move()` bringt ihn dorthin zurück.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

drone.chkpt("start");

drone.box("STONE_BRICKS", 3, 10, 3);

drone.move("start").right(6);
drone.box("STONE_BRICKS", 3, 10, 3);

drone.move("start").fwd(6);
drone.box("STONE_BRICKS", 3, 10, 3);

Schritt für Schritt

1. Ausgangspunkt speichern

Baue drei verschiedene Objekte vom selben Startpunkt aus.

2. Mehrere Checkpoints

Speichere zusätzlich einen Punkt namens `garten`.

3. Gebäudeteile

Baue Haupthaus, Turm und Garten voneinander getrennt.

Challenge:

Baue eine Villa mit Haupthaus, zwei Türmen und einem Garten. Verwende mindestens zwei verschiedene Checkpoints.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

drone.chkpt("haus");

drone.box0("WHITE_CONCRETE", 12, 5, 10);
drone.up(5).box("QUARTZ_BLOCK", 12, 1, 10);

drone.move("haus").left(4);
drone.box("STONE_BRICKS", 3, 9, 3);

drone.move("haus").right(13);
drone.box("STONE_BRICKS", 3, 9, 3);

drone.move("haus").fwd(13);
drone.chkpt("garten");
drone.box("GRASS_BLOCK", 12, 1, 8);

drone.move("garten").right(5).up(1);
drone.box("OAK_LOG", 1, 4, 1).up(4).sphere("OAK_LEAVES", 2);
Typische Fehler
  • Checkpoint-Namen sind Text und brauchen Anführungszeichen.
  • `move()` stellt auch die Blickrichtung wieder her.
  • Gleiche Checkpoint-Namen überschreiben frühere Positionen.

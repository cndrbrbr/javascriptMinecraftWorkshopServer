Funktionen – eigene Baubefehle

JavaScript
Funktionen, Wiederverwendung, Abstraktion
Minecraft-Projekt
Häuserfabrik
Lernziel
Die Kinder fassen wiederverwendbaren Code in einer eigenen Funktion zusammen.

Wir bringen Minecraft einen neuen Befehl bei: `haus()`.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

function haus() {
    drone.box0("OAK_PLANKS", 7, 4, 7);
    drone.up(4);
    drone.box("STONE_BRICKS", 7, 1, 7);
    drone.down(4);
}

haus();
drone.right(10);
haus();
drone.right(10);
haus();

Schritt für Schritt

1. Funktion benennen

Probiere einen anderen Funktionsnamen, z. B. `kleinesHaus`.

2. Mehrfach aufrufen

Baue fünf Häuser in einer Reihe.

3. Kombination

Verwende eine Schleife, um `haus()` mehrfach aufzurufen.

Challenge:

Baue mit einer Funktion und einer Schleife eine Reihe aus 8 gleichen Häusern.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

function haus() {
    drone.box0("OAK_PLANKS", 7, 4, 7);
    drone.up(4).box("STONE_BRICKS", 7, 1, 7);
    drone.down(4);
}

for (var i = 0; i < 8; i++) {
    haus();
    drone.right(10);
}
Typische Fehler
  • Die Funktion wird erst ausgeführt, wenn sie aufgerufen wird: `haus();`.
  • Funktionsnamen brauchen beim Aufruf runde Klammern.
  • Die Position des Drone bleibt nach der Funktion verändert, wenn du sie nicht zurücksetzt.

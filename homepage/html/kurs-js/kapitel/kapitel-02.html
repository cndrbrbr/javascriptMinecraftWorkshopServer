Variablen – unser Bauplan

JavaScript
Variablen, Zahlen, Wiederverwendung
Minecraft-Projekt
Ein einfaches Haus
Lernziel
Die Kinder speichern Werte in Variablen und verändern damit ein ganzes Bauwerk an einer Stelle.

Wir wollen ein Haus bauen, dessen Größe leicht verändert werden kann.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

var breite = 7;
var hoehe = 4;
var tiefe = 9;

drone.box0("OAK_PLANKS", breite, hoehe, tiefe);
drone.up(hoehe);
drone.box("STONE_BRICKS", breite, 1, tiefe);

Schritt für Schritt

1. Größen ändern

Verändere nur `breite`, `hoehe` und `tiefe`.

2. Material ändern

Lege zusätzlich `var wand = "OAK_PLANKS";` an und verwende die Variable.

3. Nachricht ausgeben

Gib nach dem Bau eine Nachricht mit den Maßen aus.

Challenge:

Baue drei Varianten desselben Hauses: klein, breit und hoch. Ändere dafür jeweils nur die Variablen.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

var breite = 10;
var hoehe = 6;
var tiefe = 7;
var wand = "BIRCH_PLANKS";

drone.box0(wand, breite, hoehe, tiefe);
drone.up(hoehe);
drone.box("STONE_BRICKS", breite, 1, tiefe);
player.sendMessage("Haus fertig: " + breite + " x " + hoehe + " x " + tiefe);
Typische Fehler
  • Variablennamen dürfen keine Leerzeichen enthalten.
  • Textwerte brauchen Anführungszeichen, Zahlen nicht.
  • `var breite = 7;` legt die Variable an; später reicht `breite = 10;`.

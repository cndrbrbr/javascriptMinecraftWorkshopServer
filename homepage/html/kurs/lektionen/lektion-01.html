Lernziel
Blockly-Blöcke zusammenstecken, 3D-Vorschau benutzen und das erste Programm als JavaScript herunterladen.

JSMN IDE öffnen →

Für Lehrkräfte: Noch keine Schleifen oder Variablen erklären. Wichtig ist nur: Die Blöcke werden von oben nach unten ausgeführt und erzeugen JavaScript.

So sieht der Blockly-Bauplan aus

function podest
box Gold 5 1 5
end function
preview function podest

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Öffne die JSMN IDE über den grünen Button.
  2. Ziehe `function` in den Arbeitsbereich und nenne sie `podest`.
  3. Hänge einen `box`-Block an und wähle Gold, 5 × 1 × 5.
  4. Beende mit `end function` und `preview function podest`.
  5. Klicke auf **3D Vorschau**.

Was Blockly daraus als JavaScript macht

function podest() {
  drone.box("GOLD_BLOCK", 5, 1, 5);
};
podest();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Ändere Material und Größe so, dass dein ganz persönlicher Startplatz entsteht.

Typische Stolperstellen
  • Der Name in `preview function` muss zum Funktionsnamen passen.
  • Ohne `preview function` weiß die 3D-Vorschau nicht, welche Funktion sie starten soll.

Schleifen – Arbeit sparen

JavaScript
for-Schleifen, Zähler, Wiederholungen
Minecraft-Projekt
Straßenlaternen
Lernziel
Die Kinder erkennen Wiederholungen und ersetzen kopierten Code durch eine Schleife.

Zehn Laternen einzeln zu programmieren wäre langweilig. Eine Schleife wiederholt denselben Bauplan automatisch.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

for (var i = 0; i < 10; i++) {
    drone.box("OAK_LOG", 1, 4, 1);
    drone.up(4);
    drone.box("GLOWSTONE", 1, 1, 1);
    drone.down(4);
    drone.fwd(5);
}

Schritt für Schritt

1. Anzahl ändern

Ändere die 10 auf 5, 20 oder 30.

2. Abstand ändern

Verändere `fwd(5)`.

3. Laterne gestalten

Verwende andere Materialien oder baue oben zwei Lampen.

Challenge:

Programmiere 20 Straßenlaternen mit 6 Blöcken Abstand.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

for (var i = 0; i < 20; i++) {
    drone.box("OAK_LOG", 1, 4, 1);
    drone.up(4).box("SEA_LANTERN");
    drone.down(4).fwd(6);
}
Typische Fehler
  • In `for (...)` stehen drei Teile: Start, Bedingung, Veränderung.
  • Die geschweiften Klammern markieren, was wiederholt wird.
  • Wenn der Drone am Ende jeder Runde nicht weiterbewegt wird, entstehen alle Laternen am selben Ort.

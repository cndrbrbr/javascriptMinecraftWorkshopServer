Entscheidungen mit if und else

JavaScript
Bedingungen, Vergleiche, Modulo
Minecraft-Projekt
Abwechslungsreiche Fassaden
Lernziel
Die Kinder lassen ihr Programm abhängig von Bedingungen unterschiedliche Entscheidungen treffen.

Programme können nicht nur wiederholen – sie können entscheiden.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

var stockwerke = 12;

for (var i = 0; i < stockwerke; i++) {
    if (i % 2 == 0) {
        drone.box0("WHITE_CONCRETE", 9, 3, 9);
    } else {
        drone.box0("GLASS", 9, 3, 9);
    }

    drone.up(3);
}

Schritt für Schritt

1. Gerade und ungerade

Beobachte, welche Stockwerke welches Material bekommen.

2. Andere Regel

Verwende `i % 3 == 0` und beschreibe das Muster.

3. Nachricht

Gib bei einem hohen Haus eine andere Meldung als bei einem kleinen aus.

Challenge:

Baue ein 18-stöckiges Hochhaus, bei dem jedes dritte Stockwerk aus GLASS und alle anderen aus WHITE_CONCRETE bestehen.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

var stockwerke = 18;

for (var i = 0; i < stockwerke; i++) {
    if (i % 3 == 0) {
        drone.box0("GLASS", 9, 3, 9);
    } else {
        drone.box0("WHITE_CONCRETE", 9, 3, 9);
    }
    drone.up(3);
}
Typische Fehler
  • `==` vergleicht Werte; `=` weist einen Wert zu.
  • `%` liefert den Rest einer Division.
  • Bei komplizierten Bedingungen erst mit Chat-Nachrichten testen, bevor gebaut wird.

Mein erstes Programm

JavaScript
Anweisungen, Strings, Methodenaufrufe
Minecraft-Projekt
Persönlicher Startplatz
Lernziel
Die Kinder verstehen, dass ein Programm aus Anweisungen besteht, die nacheinander ausgeführt werden.

Wir starten mit etwas, das sofort sichtbar wird: einer Nachricht im Chat und einem Block in der Welt.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

player.sendMessage("Hallo Minecraft!");
drone.box("GOLD_BLOCK", 1, 1, 1);

Schritt für Schritt

1. Text verändern

Ändere die Nachricht und starte das Script erneut.

2. Material verändern

Ersetze GOLD_BLOCK zum Beispiel durch DIAMOND_BLOCK, EMERALD_BLOCK oder RED_WOOL.

3. Größe verändern

Probiere `drone.box("GOLD_BLOCK", 3, 3, 3);` und beobachte, was die drei Zahlen bewirken.

Challenge:

Baue einen persönlichen Startplatz aus einem 5×1×5 großen Material deiner Wahl und begrüße dich mit deinem Minecraft-Namen.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

player.sendMessage("Willkommen, " + player.getName() + "!");
drone.box("EMERALD_BLOCK", 5, 1, 5);
Typische Fehler
  • Materialnamen müssen groß geschrieben werden, z. B. `GOLD_BLOCK`.
  • Text steht in Anführungszeichen.
  • Jede Anweisung endet am besten mit einem Semikolon.

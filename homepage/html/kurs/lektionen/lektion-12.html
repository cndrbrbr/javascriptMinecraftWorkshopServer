Variablen

preview function meinStadtteil

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Plant euren Stadtteil zuerst auf Papier.
  2. Teilt wiederkehrende Bauobjekte in eigene Funktionen auf.
  3. Verwendet mindestens eine Schleife und eine Variable.
  4. Verwendet mindestens eine Entscheidung.
  5. Prüft jeden Teil in der 3D-Vorschau, bevor ihr ihn nach Minecraft übertragt.
  6. Präsentiert zum Schluss nicht nur das Bauwerk, sondern auch eure Programmieridee.

Was Blockly daraus als JavaScript macht

// Beispielhafte Struktur
var anzahl = 6;

function baum() {
  drone.box("IRON_BLOCK",1,4,1); // Material natürlich frei wählen
}

function meinStadtteil() {
  for (var i=0; i<anzahl; i++) {
    baum();
    drone.right(4);
  }
}

meinStadtteil();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Pflicht: mindestens 5 Bauobjekte, eine eigene Hilfsfunktion, eine Schleife, eine Variable und eine if/else-Entscheidung. Bonus: mehrere Modelle im Team zusammenführen.

Typische Stolperstellen
  • Große Projekte in kleine, testbare Funktionen zerlegen.
  • Erst kleine Werte verwenden; danach die Dimensionen vergrößern.
  • Vor dem Download prüfen, ob `preview function` den richtigen Einstiegspunkt nennt.

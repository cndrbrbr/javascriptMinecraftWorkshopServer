Der Drone bewegt sich

JavaScript
Sequenzen, räumliches Denken, Bewegung
Minecraft-Projekt
Eine Straße
Lernziel
Die Kinder lernen den Drone als virtuellen Baumeister mit Position und Blickrichtung kennen.

Der Drone kann sich vorwärts, rückwärts, nach links, rechts, oben und unten bewegen.

Für Lehrkräfte: Erst die Aufgabe zeigen, dann das Problem gemeinsam besprechen und danach das neue JavaScript-Konzept einführen. So entsteht die Syntax aus einem sichtbaren Bauproblem.

Startcode

drone.box("GOLD_BLOCK");
drone.fwd(5);
drone.box("DIAMOND_BLOCK");
drone.right(5);
drone.box("EMERALD_BLOCK");

Schritt für Schritt

1. Bewegungen testen

Teste `fwd`, `back`, `left`, `right`, `up` und `down`.

2. Markierungen bauen

Setze an jeder neuen Position einen anderen Block.

3. Straße bauen

Erzeuge eine 5 Blöcke breite und 20 Blöcke lange Straße.

Challenge:

Baue eine Straße mit zwei Gehwegen. Die Fahrbahn soll aus STONE bestehen, die Gehwege aus SMOOTH_STONE.

Musterlösung

Die Musterlösung ist nur eine mögliche Lösung. Andere funktionierende Lösungen sind ausdrücklich erwünscht.

drone.box("STONE", 5, 1, 20);
drone.left(1);
drone.box("SMOOTH_STONE", 1, 1, 20);
drone.right(6);
drone.box("SMOOTH_STONE", 1, 1, 20);
Typische Fehler
  • Die Bewegungen beziehen sich auf die Blickrichtung des Drone.
  • `right(5)` bewegt fünf Blöcke, baut aber nichts.
  • Wenn das Ergebnis unerwartet liegt, stelle dich vor dem Start bewusst in eine eindeutige Richtung.

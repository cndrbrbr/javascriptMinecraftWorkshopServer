# JavaScript in Minecraft – Kurswebsite

In `cndrbrbr/webscriptcraft` liegt dieser Ordner unter `openb3/kurs-js/`,
verlinkt von der Übersichtsseite (`openb3/index.html`).

## Struktur

- index.html
- assets/style.css
- kapitel/kapitel-01.html bis kapitel-12.html

Alle Links und CSS-Pfade sind relativ.

## Veröffentlichen

Den kompletten Ordner auf den Webserver kopieren. Danach `index.html` aufrufen.

Beispiele:

- Apache/Nginx: Ordner unterhalb des DocumentRoot ablegen
- GitHub Pages: Inhalt in ein Repository bzw. einen `docs/`-Ordner legen
- Schulserver: Ordner in den Webspace kopieren

Es sind keine externen Bibliotheken oder CDNs nötig.

Für Lehrkräfte: Lass die Kinder vor jeder Vorschau mit dem Finger vorhersagen, wo der nächste Block erscheinen wird.

So sieht der Blockly-Bauplan aus

function spur
box Gold 1 1 1
fwd 4
box Diamond 1 1 1
right 4
box Emerald 1 1 1
end function
preview function spur

Die Darstellung hier ist eine schematische Lernhilfe. In der IDE werden die echten Blockly-Blöcke aus der Werkzeugkiste verwendet.

Schritt für Schritt

  1. Baue zuerst einen einzelnen Goldblock.
  2. Bewege die Drohne 4 Blöcke vorwärts und baue einen Diamantblock.
  3. Bewege sie 4 Blöcke nach rechts und baue einen Smaragdblock.
  4. Teste anschließend `left`, `back`, `up`, `down` und `turn`.

Was Blockly daraus als JavaScript macht

function spur() {
  drone.box("GOLD_BLOCK",1,1,1);
  drone.fwd(4);
  drone.box("DIAMOND_BLOCK",1,1,1);
  drone.right(4);
  drone.box("EMERALD_BLOCK",1,1,1);
};
spur();
JavaScript-Brücke: Vergleicht die Blöcke mit dem Code. Welche Zeile gehört zu welchem Block?
Challenge:

Baue vier Markierungen an den Ecken eines Quadrats. Verwende Bewegung und mindestens eine Drehung.

Typische Stolperstellen
  • `move` baut nichts; er verändert nur die Position.
  • `left` und `right` sind relativ zur Blickrichtung der Drohne.
